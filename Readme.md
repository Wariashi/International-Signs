## Config

The config file should look like this:

```yaml
database:
  password: <password>
  url: <url>
  user: <user>
```

#### <database.password>

The password that is used to access the database.

#### <database.url>

The URL that is used to access the database.

#### <database.user>

The user that is used to access the database.
